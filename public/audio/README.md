# Forever in Bloom

An original 32-second instrumental loop synthesized for this invitation with `scripts/create-ambient-music.ts`. No sampled recordings or third-party compositions are used. The source generator and recording may be used and modified with this project.

Regenerate with `bun run scripts/create-ambient-music.ts`. The mono 24 kHz PCM WAV is requested after a guest chooses music. Set `NEXT_PUBLIC_MUSIC_SRC` to use a different licensed track, or `off` to hide the music feature.
